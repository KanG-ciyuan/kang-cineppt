# 视觉规范

## 先用画面建立层次

电影感来自有目的的构图、尺度、明暗、空间与运动关系。以巨浪和小帆船为例，近处白浪、中景船体、远处蓝色海流形成可辨识的层次。普通货轮平移即使补到高帧率，也不会自动获得同样的冲击力。

- 主体与环境有尺度关系；水纹、尾流和浪花持续运动。
- 选择能承载文字的水面区域，但整页保持真实画面，不留一块静态色卡。
- 保留暗部纹理和高光细节。提亮是为了看清海水，不是把所有区域变成同一亮度。
- 避免廉价耀光、夸张飞入、反复缩放、厚重遮罩和无必要的转场。

## 排版

中文标题、引题、辅助文字形成清楚层级。细线服务于对齐和节奏；不要为“高级”堆叠装饰。与主体保持足够距离，也不要让整侧只剩空海水和一个小标题。

参考案例采用Songti SC与Arial，白色及浅蓝文字。字体是风格选择，不是必须依赖；替换为有合法使用权且目标机器可用的字体后，重查字宽、换行与位置。不得随包复制系统字体。

## 动态节奏

| 项目 | 原则 |
|---|---|
| 出场顺序 | 视频场景先建立，再让文字淡入 |
| 字幕完整性 | 短场景尽早完成全部文字，留出阅读时间 |
| 入口动画 | 短片默认原生整组淡入；需要分批时按绝对时间表实播核对 |
| 背景循环 | 首尾不连续就播放一次，切页或收尾 |
| 帧率 | 记录原始、处理、导出三种帧率，不把补帧当成原生拍摄 |
| 宣传视频 | 按观看节奏控制总长；不靠长停帧等待字幕 |

## 本案例的设计范围

只参考《向海而行》实际页面的机制，不强迫所有主题使用海洋、宋体或左侧布局。普通图文PPT不需要强加动态背景；复杂商业演示也不应从两页案例直接推导出已验证的整套生产能力。


## 从新案例提炼的用途约束

工作汇报收尾需要一句能接住前文的表达，不能只堆风景与诗句。庄重主题优先从国旗、秩序、山河与职责关系建立画面，不把街头日常、过多装饰或旅游信息强行加入。

自然留白应随视频运动检查。保持用户认可的色调；大浪、山峰或城墙的层次与尺度比单纯提高帧率更重要。探索不符合方向时，保留取舍理由，另换素材，不以添加特效掩盖构图问题。
