# 制作流程

## 先形成可执行的小样方案

确认参考、文案、比例、两页分别承担的画面信息，以及最终是放映还是发视频。已有成功素材优先复用。先让Agent在内部比较机位、尺度与动态层次，再提出有理由的方案，不把所有小决定交给用户。

| 阶段 | 决策与动作 | 保留的证据 |
|---|---|---|
| 参考分析 | 看全片并抽帧；读取实际文件参数；分开分析画面、排版和出字节奏 | 关键帧、参数、设计说明 |
| 素材计划 | 选主体与尺度反差；整页水纹持续运动；明确运动方向和留字区 | 每页画面描述与时长 |
| 费用确认 | 现场核对模型、能力和报价；计算本次次数与总额 | 用户授权的预算，不保存账户隐私 |
| 背景生成或复用 | 仅执行获批次数；轮询不等于重新提交；成功后下载并保留原片 | 无密钥的任务结果摘要 |
| 本地修整 | 原片参数检查，必要时提亮与运动插值，检视浪边和尾流 | 原片与处理版、处理参数 |
| 原生排版 | 视频全屏嵌入；所有中文、页码、线条为原生对象 | 可编辑母版 |
| 时序 | 视频先开始；全部字及时淡入；不连续素材只播放一次 | 每页时序表 |
| 实播和导出 | 目标软件从页首放映；按需原生导出MP4 | 实际软件、观察结果、成片参数 |
| 交付 | 母版、背景、成片和边界说明 | 输出文件与校验摘要 |

## 失败与降级

- API失败或超时：保留已有结果，不自动重新发起付费调用；与用户决定是否追加。
- 没有合法API或预算：用现有视频，不伪造生成成功。
- 没有授权的演示工具：保留方案与素材，说明可编辑母版尚未完成。
- 不能实际放映：可以检查包结构，但交付说明必须写明自动播放和时序未实播。
- 不会无缝循环：播放一次并切页。不要使用正放加倒放掩盖首尾断裂。
- 用户禁止新作品、安装或测试：这些限制优先，本次只整理和静态审查。

## 目录建议

每次创作在用户指定工作区保留`sources/`、`work/`和`outputs/`。只把最终产物作为交付；凭据位于宿主的受控配置，不复制到任务目录。不要写死作者机器路径。
