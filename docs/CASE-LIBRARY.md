## 为什么把视频和 PPTX 放在 Release

首页保留轻量动态节选与静态效果图；完整成片和两份母版作为版本附件下载，避免把多个大二进制放进 Git 历史。文件名、大小和 SHA-256 见 [版本附件清单](../reports/release-assets.json)。

PPTX 的视频已内嵌，中文文字与细线可编辑。新案例现场版由讲演者按空格翻页，背景自动正向播放一次；宣传 MP4 固定切页。不承诺跨软件时序一致，字体替换后需实播。
