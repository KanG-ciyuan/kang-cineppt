# 小白也能做的动态 PPT 收尾

先想一句适合自己汇报的结尾，再挑一段有留白、主体会自然运动的视频。去 Pexels 等素材站核对许可，下载后先看完整片段，确认后半段不会挡住文字。

1. 新建 16:9 PPT，每页铺满一段视频，设为自动播放、只播放一次。
2. 在视频上方放可编辑标题与一两行正文。用一套字体，字号拉开，不用大色块盖住风景。
3. 让画面先动约半秒，再让全部文字淡入。短片尽早出完字，给观众留阅读时间。
4. 素材不够长，优先换较长片段；不要倒放或循环回到起点。
5. 从幻灯片开头完整播放，检查视频、文字和翻页。只点视频播放看不到整页动画。
6. 需要发视频时，用演示软件导出影片，再检查开头、出字、切页与结尾。Keynote 的“翻页前等待”可能是额外时长，不要直接填目标页面秒数。

先做两页就够。想用 AI 协作，可以这样说：

> 帮我做两页工作汇报结尾的动态PPT。先找免费授权素材，让我看动态与色调再制作。视频铺满全页，中文文字和细线能编辑，画面先动、文字尽早淡入。交付PPTX和完整MP4，并说明实际在哪个软件验证过。
